## Why tree-sitter-language-pack

<CardGrid>
    <Card title="Parse any language without wiring up grammars" icon="random">
        One install covers 371 languages — Python, Rust, Go, Java, TypeScript, C++, Kotlin, Swift, Zig,
        Elixir, Haskell, Julia, R, and hundreds more. Nothing to compile, nothing to fetch by hand.
    </Card>
    <Card title="Fast enough for real-time tooling" icon="rocket">
        Parsing keeps up with editor keystrokes and large-repo scans, so you can build linters, formatters,
        and analysis that respond instantly.
    </Card>
    <Card title="Only download the parsers you use" icon="download">
        The base install stays small. Each parser is fetched and cached the first time you touch its
        language, so you never ship 371 grammars you don't need.
    </Card>
    <Card title="Find functions, classes, and imports in one call" icon="magnifier">
        Go past raw syntax trees: pull functions, classes, imports, exports, symbols, comments, and
        docstrings out of any file with a single call.
    </Card>
    <Card title="Chunk code your LLM can actually use" icon="document">
        Split source at real boundaries — functions, classes, blocks — so each chunk stays whole for
        embeddings and prompt windows instead of cutting mid-statement.
    </Card>
    <Card title="Use your language's own parser types" icon="translate">
        In Python, Node.js, Go, Java, C#, Kotlin, Swift, Zig, and C, `get_language()` hands back your
        ecosystem's native `Language` object, ready to pass to your existing parser.
    </Card>
</CardGrid>

## Language support

| Language                 | Install                                                                | Docs                                              |
| :----------------------- | :--------------------------------------------------------------------- | :------------------------------------------------ |
| **Python**               | `pip install tree-sitter-language-pack`                                | [API Reference](/reference/api-python/)           |
| **TypeScript / Node.js** | `npm install @xberg-io/tree-sitter-language-pack`                      | [API Reference](/reference/api-typescript/)       |
| **Rust**                 | `cargo add tree-sitter-language-pack`                                  | [API Reference](/reference/api-rust/)             |
| **Go**                   | `go get github.com/xberg-io/tree-sitter-language-pack/packages/go`     | [API Reference](/reference/api-go/)               |
| **Java**                 | Maven Central `io.xberg.treesitterlanguagepack`                        | [API Reference](/reference/api-java/)             |
| **Kotlin (Android)**     | Maven `io.xberg.tslp.android:tree-sitter-language-pack-android`        | [API Reference](/reference/api-kotlin-android/)   |
| **C#**                   | `dotnet add package XbergIo.TreeSitterLanguagePack`                    | [API Reference](/reference/api-csharp/)           |
| **Ruby**                 | `gem install tree_sitter_language_pack`                                | [API Reference](/reference/api-ruby/)             |
| **PHP**                  | `composer require xberg-io/tree-sitter-language-pack`                  | [API Reference](/reference/api-php/)              |
| **Elixir**               | `{:tree_sitter_language_pack, "~> 1.14"}`                               | [API Reference](/reference/api-elixir/)           |
| **Dart / Flutter**       | `dart pub add tree_sitter_language_pack`                               | [API Reference](/reference/api-dart/)             |
| **Swift**                | Swift Package Manager                                                  | [API Reference](/reference/api-swift/)            |
| **Zig**                  | `zig fetch --save` from GitHub                                         | [API Reference](/reference/api-zig/)              |
| **WebAssembly**          | `npm install @xberg-io/tree-sitter-language-pack-wasm`                 | [API Reference](/reference/api-wasm/)             |
| **C (FFI)**              | Shared library + header                                                | [API Reference](/reference/api-c/)                |
| **CLI**                  | `brew install xberg-io/tap/ts-pack`                           | [CLI Guide](/guides/cli/)                         |
